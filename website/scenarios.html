SCENARIOS / 24 USE CASES

One phone: a remote, a server, a lab.

Each card is a task the agent can attempt with registered native tools. Open it for a prompt you can say out loud and the exact tool chain behind it. Hardware, permissions and optional integrations decide what actually runs.

HardwareNetworkMediaData & automationDevelopmentQuick ideas

Use these only on hardware, accounts and tags you own or are authorised to operate.

01 / HARDWARE & PERIPHERALS

Reach the parts the OS hides

Radio, tags, torch, haptics and USB — whatever this specific phone ships with.

📱Hardware
01 / 24

Read the phone like a spec sheet

Model, system version, storage pressure, battery and network in one report.

Prompt & tool chain
YOU SAY
Summarise this phone: model, Android version, storage usage, battery health and carrier. Tell me what is worth worrying about.
TOOL CHAIN
device_infobattery_detailstorage_scantelephony_info

Battery health fields depend on what the OEM exposes to the BatteryManager API.

Prompt & tool chain
YOU SAY

TOOL CHAIN

06 / QUICK IDEAS

One-liners worth trying

Small prompts that still touch real APIs. Combine them freely.

  • 🗂️
    Batch rename downloadsfile_list → file_rename
  • #️⃣
    Find duplicates by hashfile_hash → file_delete
  • 🗜️
    Zip and share a folderzip_create → file_share
  • 🔐
    Encrypt a sensitive filefile_encrypt → file_hash
  • 📋
    Clipboard to clean tableclipboard_read → json_fix
  • ✉️
    Dig a verification code out of SMSsms_read → clipboard_write
  • 👥
    Search contacts and call logcontacts_search → call_log_read
  • 👟
    Weekly step summarysteps_today → steps_history
  • 🔋
    Charge-level remindercron_create → battery_detail → notify_send
  • 📦
    Audit installed appsapp_list → app_details
  • 🎚️
    Set volume, wallpaper, ringtoneaudio_set_volume → wallpaper_set
  • 🖥️
    Brightness and rotation presetsbrightness_set → screen_orientation_set

Tool names mirror the registry in source; availability changes with device, permissions and version.
