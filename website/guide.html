GET STARTED

From APK to first conversation

You need an Android 8.0+ device and an OpenAI-compatible model endpoint.

1. Install the APK

Open GitHub Releases and download the latest APK. Install it on your Android device. Releases are debug-signed; Android may prompt you to allow installation from this source.

Open Releases ↗

The embedded Termux userland needs an arm64-v8a device; basic chat and other tools do not require it.

2. Connect a model

On first launch, “Connect a model” opens automatically if no model is configured. Select a provider preset or a custom OpenAI-compatible endpoint, enter the API key and model ID, then choose “Test and save”. The test sends a short model request and may incur a small charge.

If model listing fails, type the model ID manually. You can also choose “Save without testing”. Ollama and LM Studio can use an empty key. For a model on your computer, use its LAN IP instead of localhost.

To reopen setup later, tap the model name in the chat header or use Settings › Model configuration.

Alternative: config.json

You can put a config.json file in the device Download directory. For Android 11+, also copy it to the app-specific external files directory; direct reads of public Downloads may be denied.

{
  "baseUrl": "https://your-endpoint.example/v1",
  "apiKey": "your-api-key",
  "model": "your-model-id"
}
adb push config.json /sdcard/Download/config.json
adb push config.json /sdcard/Android/data/com.dc.andagent/files/config.json

Use the endpoint base URL without /chat/completions. File values override saved in-app settings when settings are read. Update or remove the file if you switch to in-app setup. Keep it out of version control because it contains a plaintext key.

3. Start a conversation

Ask a simple question, then try a device task such as checking battery details. Android permissions are requested when the relevant tool runs; some media and microphone permissions are requested at startup. Advanced capabilities may need Shizuku or other setup.
